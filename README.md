# 和弦地图 · Chord Map

面向吉他练习的中文和弦对照页。默认范围为 **0–15 品**，支持 12 个根音、23 种和弦构造、CAGED、转位指形、试听与节拍跟练。

## 本地使用

需要 Node.js 20 或更新版本，无须安装第三方依赖。

```sh
npm run dev
```

打开终端显示的本机地址（默认 `http://127.0.0.1:8767/`）。也可以直接打开仓库中的 `guitar-fretboard-offline.html`，离线版包含所需脚本和样式。

```sh
npm test
npm run build
```

`npm test` 检查和弦构成、音名拼写、指法、实际最低音、转位分类与省略音；`npm run build` 重新生成离线单文件。

## 功能与练习

- **指板对照**：音名、和弦度数、根音及三音/七音聚焦；默认 0–15 品，另有 0–12 品基础范围与 0–24 品完整参考。
- **常用按法**：实际要弹的位置与全部可选和弦音分开显示，省略音明确标出。
- **转位指形**：按真实最低音区分原位、第一/第二/第三转位，并显示斜线和弦名、低音、发声音序与不同位置的按法。
- **CAGED**：五种形状按当前根音在指板上的位置从低到高排列。
- **跟练**：性质对照、CAGED、声部连接、延伸音；提供合成音试听、节拍器与四拍换和弦。

三和弦按根音、三音、五音在低音的位置命名转位；七和弦另有七音低音的第三转位。延伸和弦沿三/七和弦骨架标记，可能省去部分音；sus 等结构使用明确的“2 音低音”“4 音低音”等名称。**转位由实际最低音决定，不等同于把位移动。**

## 内容说明

内容由《和弦笔记（一）大、小、属家族》整理并补充练习，修正了 sus/add9、C6 与 Am7/C、自然 11/13 等易混淆之处。参考资料在页面的“内容来源与阅读说明”中列出。

网站使用标准调弦 E–A–D–G–B–E（6→1 弦）。指板按均匀间距绘制；合成音帮助比较音程，并非吉他录音。指形标记品位与实际发声位置，可依自己的手型选择适合的按法。
